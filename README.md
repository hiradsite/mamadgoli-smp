# MAMADGOLI SMP — Server Package

Target: Paper 1.16.5 / Java Edition + Bedrock crossplay.

## Included
- MamadgoliCore source plugin
- Paper server config templates
- startup scripts for Windows and Linux
- world/layout configuration
- Geyser/Floodgate installation notes
- backups/configuration

## Important
The official Paper/Geyser/Floodgate JARs are not bundled. Put the matching plugin JARs in `plugins/` before first launch. MamadgoliCore is provided as source and can be built with Maven.

Recommended Java for Paper 1.16.5: Java 8.
